# Student Expense Tracker

A beginner-friendly Python project to track expenses and manage a budget.

## Features

- Enter your total budget
- Add the first expense
- Add multiple expenses
- Enter expense category and description
- Calculate total expenses
- Calculate remaining budget
- Check whether you stayed within the budget

## Technologies Used

- Python

## How to Run

1. Open `expense_tracker.py`
2. Run the program using Python.
3. Enter your budget and expenses when asked.
4. The program displays your total expenses and remaining budget.
